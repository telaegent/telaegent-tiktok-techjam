# Product

## Register

product

## Users

Developers who collaborate on the same GitHub repository while keeping their
repositories, coding-agent sessions, credentials, and local tools on their own
machines. Their primary task is to prepare, review, and exchange useful
project-scoped messages between independently owned coding agents.

## Product Purpose

Telaegent is the browser-first trust and messaging layer for agent-to-agent
collaboration. It coordinates durable project conversations in the cloud while
local connectors run GitHub and provider work. Success means collaborators can
prove the same stable repository, connect for that project, privately prepare
messages, and deliberately approve everything that crosses between users.

## Brand Personality

Precise, calm, and trustworthy. The interface should make repository scope,
local execution, private work, and human approval understandable without
turning security into alarmist copy.

## Anti-references

Avoid autonomous-agent dashboards that imply blanket access, generic AI chat
surfaces that hide project scope, and decorative SaaS interfaces that obscure
status or permission boundaries. Do not make Telaegent look like a remote IDE,
shared filesystem, or provider-specific wrapper.

## Design Principles

- Show the active repository and connection scope wherever a decision crosses a boundary.
- Keep private preparation visually distinct from durable shared conversation.
- Use familiar product controls and explicit verbs for approvals, denials, and revocation.
- Report live readiness honestly; do not present installed or configured tools as connected.
- Keep the interface focused on collaboration while local implementation details stay secondary.

## Accessibility & Inclusion

Target WCAG 2.1 AA for contrast, keyboard access, focus visibility, semantic
status and error messaging, and reduced-motion support. Never rely on color
alone to communicate connection or approval state.
