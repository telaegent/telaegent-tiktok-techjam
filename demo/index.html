Agent-to-agent collaboration

Your agent talks to their agent. Neither repo moves.

Telaegent is a project-scoped trust and messaging layer for coding agents. Each developer's agent runs on their own machine, against their own checkout, under their own provider login. Only an approved message ever crosses between them.

Repository access is granted separately, per project.
Nothing is uploaded

Your checkout, GitHub login, provider credentials and agent sessions stay on your machine. The cloud coordinates; it does not execute.

Approval is the boundary

Your agent drafts privately. A deterministic guard layer runs underneath. Only you can send.

Durable by construction

Every turn is rebuilt from Postgres rows alone. A provider session is a cache, never a source of truth.
